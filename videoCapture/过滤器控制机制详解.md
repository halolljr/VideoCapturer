# FFVFilter和FFAFilter控制机制详解

## 过滤器架构概述

这个项目采用了**双过滤器架构**：
- **FFVFilter**: 视频过滤器，处理视频流的叠加和合成
- **FFAFilter**: 音频过滤器，处理音频流的混音和音量控制

每个过滤器都有对应的线程：
- **FFVFilterThread**: 视频过滤线程
- **FFAFilterThread**: 音频过滤线程

### 1.4 视频过滤主循环
```cpp
void FFVFilterThread::run() {
    while(!m_stop) {
        // 检查各流状态
        bool hasVideo = videoFlag.load();
        bool hasScreen = screenFlag.load();
        bool hasCamera = cameraFlag.load();
        bool hasEncoder = encoderFlag.load();
        bool hasPause = pauseFlag.load();
        
        // 如果没有任何流，等待
        if(!hasVideo && !hasScreen && !hasCamera && !hasEncoder) {
            std::unique_lock<std::mutex> lock(mutex);
            cond.wait_for(lock, std::chrono::milliseconds(100));
            continue;
        }
        
        // 处理屏幕流
        if(hasScreen) {
            screenFrame = frmQueue1->dequeue();
            if(screenFrame != nullptr) {
                QMetaObject::invokeMethod(capWindow, "sendScreenFrame",
                    Qt::QueuedConnection,
                    Q_ARG(AVFrame*, av_frame_clone(screenFrame)));
            }
        }
        
        // 处理摄像头流（人脸检测）
        if(hasCamera) {
            cameraFrame = frmQueue2->dequeue();
            if(cameraFrame != nullptr) {
                cameraFrame2 = faceDetector->detectFace(cameraFrame);
                QMetaObject::invokeMethod(capWindow, "sendCameraFrame",
                    Qt::QueuedConnection,
                    Q_ARG(AVFrame*, av_frame_clone(cameraFrame2)));
            }
        }
        
        // 处理视频文件流
        if(hasVideo) {
            // 时间同步处理
            if(!eofFlag) {
                if(lastVideoTime == 0) {
                    lastVideoTime = av_gettime_relative();
                    videoFrame = frmQueue3->dequeue();
                }
                else {
                    int64_t currentVideoTime = av_gettime_relative();
                    if(currentVideoTime - lastVideoTime >= 33000) { // 33ms
                        videoFrame = frmQueue3->dequeue();
                        lastVideoTime = currentVideoTime;
                    }
                }
                
                if(videoFrame != nullptr) {
                    QMetaObject::invokeMethod(capWindow, "sendVideoFrame",
                        Qt::QueuedConnection,
                        Q_ARG(AVFrame*, av_frame_clone(videoFrame)));
                }
            }
        }
        
        // 按叠加顺序合成最终画面
        overlayNumbers = capWindow->getOverlayNumbers();
        for(auto iter = overlayNumbers.rbegin(); iter != overlayNumbers.rend(); ++iter) {
            int type = *iter;
            if(type == CAMERA && cameraFrame2 && hasCamera) {
                overlayFrame(av_frame_clone(cameraFrame2), type);
                av_frame_free(&cameraFrame2);
            }
            else if(type == SCREEN && screenFrame && hasScreen) {
                overlayFrame(av_frame_clone(screenFrame), type);
                av_frame_free(&screenFrame);
            }
            else if(type == VIDEO && lastVideoFrame && hasVideo) {
                videoFrame2 = av_frame_clone(lastVideoFrame);
                overlayFrame(av_frame_clone(videoFrame2), type);
                av_frame_free(&videoFrame2);
            }
        }
        
        // 编码帧处理
        if(hasEncoder && !hasPause) {
            std::lock_guard<std::mutex> lock(mutex);
            AVFrame* encodeFrame = overlayProcessor->getOverlayFrame();
            
            // 时间戳计算
            auto end = av_gettime_relative();
            int64_t duration = (end - start) * 10;
            overlayPts = av_gettime_relative() * 10 + duration - pauseTime * 10;
            encodeFrame->pkt_dts = overlayDts;
            encodeFrame->pts = overlayPts;
            
            filter->sendEncodeFrame(encodeFrame);
            overlayProcessor->resetBackground();
        }
    }
}
```

### 2.4 音频过滤主循环
```cpp
void FFAFilterThread::run() {
    while(!m_stop) {
        bool microphoneActive = microphoneFlag.load(std::memory_order_seq_cst);
        bool audioActive = audioFlag.load(std::memory_order_seq_cst);
        bool encoderActive = encoderFlag.load(std::memory_order_seq_cst);
        bool pauseActive = pauseFlag.load(std::memory_order_seq_cst);
        
        // 如果没有任何流，等待
        if(!microphoneActive && !audioActive && !encoderActive) {
            std::unique_lock<std::mutex> lock(mutex);
            cond.wait_for(lock, std::chrono::milliseconds(100));
            continue;
        }
        
        int64_t start = av_gettime_relative() * 10;
        
        // 混音处理：【声卡】 + 【麦克风】
        if(audioActive && microphoneActive) {
            audioFrame = frmQueue1->dequeue();
            microphoneFrame = frmQueue2->dequeue();
            
            if(encoderActive && !pauseActive) {
                int ret = filter->sendFilter(audioFrame, microphoneFrame, start, pauseTime);
                if(ret < 0) {
                    std::cerr << "FilterThread Fail !" << std::endl;
                    m_stop = true;
                }
            }
            else {
                // 释放帧资源
                if(audioFrame) {
                    av_frame_unref(audioFrame);
                    av_frame_free(&audioFrame);
                }
                if(microphoneFrame) {
                    av_frame_unref(microphoneFrame);
                    av_frame_free(&microphoneFrame);
                }
            }
        }
        // 单流处理：【声卡】
        else if(audioActive) {
            audioFrame = frmQueue1->dequeue();
            if(encoderActive && !pauseActive) {
                filter->sendSingleFilter(audioFrame, start, pauseTime, AUDIO);
            }
            else {
                if(audioFrame) {
                    av_frame_unref(audioFrame);
                    av_frame_free(&audioFrame);
                }
            }
        }
        // 单流处理：【麦克风】
        else if(microphoneActive) {
            microphoneFrame = frmQueue2->dequeue();
            if(encoderActive && !pauseActive) {
                filter->sendSingleFilter(microphoneFrame, start, pauseTime, MICROPHONE);
            }
            else {
                if(microphoneFrame) {
                    av_frame_unref(microphoneFrame);
                    av_frame_free(&microphoneFrame);
                }
            }
        }
        // 静音包处理
        else {
            if(encoderActive && !pauseActive) {
                AVFrame* muteFrame = generateMuteFrame();
                filter->sendFrame(muteFrame, start, pauseTime);
            }
        }
    }
}
```

## 3. 队列同步机制

### 3.1 队列状态管理

```cpp
void FFVFrameQueue::start() {
    m_stop = false;

void FFVFrameQueue::close() {
    wakeAllThread();
    clearQueue();
}

// 唤醒所有等待线程
void FFVFrameQueue::wakeAllThread() {
    m_stop.store(true, std::memory_order_release);
    cond.notify_all();
```

### 3.2 线程同步控制
```cpp
// 等待队列有数据
AVFrame* FFVFrameQueue::dequeue() {
    std::unique_lock<std::mutex> lock(mutex);
    if(m_stop) {
        return nullptr;
    }
    cond.wait(lock, [this]() { return !frmQueue.empty() || m_stop.load(); });
    
    if(m_stop.load()) {
        return nullptr;
    }
    
    AVFrame* frame = frmQueue.front();
    frmQueue.pop();
    cond.notify_one();
    return frame;
}

// 等待队列有空间
void FFVFrameQueue::enqueue(AVFrame* srcFrame) {
    std::unique_lock<std::mutex> lock(mutex);
    cond.wait(lock, [this]() { return frmQueue.size() < MAX_FRAME_SIZE || m_stop.load(); });
    
    if(m_stop.load()) {
        av_frame_unref(srcFrame);
        return;
    }
    
    AVFrame* destFrame = av_frame_alloc();
    av_frame_move_ref(destFrame, srcFrame);
    av_frame_unref(srcFrame);
    frmQueue.push(destFrame);
    cond.notify_one();
}
```

### 4.1 打开源事件

```cpp
    init();    // 初始化解复用器和解码器
    start();   // 启动相关线程

void FFOpenSourceEvent::start() {
    if(sourceType == AUDIO || sourceType == MICROPHONE) {
        // 启动音频相关线程
        aDemuxerThread[index]->start();
        aDecoderThread[index]->start();
        aPktQueue[index]->start();
        aFrmQueue[index]->start();
        aFilterThread->openAudioSource(sourceType);
    }
    else {
        // 启动视频相关线程
        vDemuxerThread[index]->start();
        vDecoderThread[index]->start();
        vPktQueue[index]->start();
        vFrmQueue[index]->start();
        vFilterThread->openVideoSource(sourceType);
    }
}
```

### 4.2 关闭源事件
```cpp
void FFCloseSourceEvent::close() {
    if(sourceType == AUDIO || sourceType == MICROPHONE) {
        // 停止音频线程
        aDemuxerThread[index]->stop();
        aDemuxerThread[index]->wakeAllThread();
        aDemuxerThread[index]->wait();
        aDemuxerThread[index]->close();
        
        aDecoderThread[index]->stop();
        aDecoderThread[index]->wakeAllThread();
        aDecoderThread[index]->wait();
        aDecoderThread[index]->close();
        
        // 清空队列
        aPktQueue[index]->close();
        aFrmQueue[index]->close();
        
        // 通知过滤器线程
        aFilterThread->closeAudioSource(sourceType);
    }
    else {
        // 视频源类似处理...
        vFilterThread->closeVideoSource(sourceType);
    }
}
```

## 5. 过滤器控制流程图

```
用户操作 → UI事件 → 事件队列 → 事件循环 → 线程池 → 具体控制逻辑
    ↓
打开源事件 → 初始化解复用器 → 启动解复用线程 → 启动解码线程 → 通知过滤线程
    ↓
过滤线程检查状态标志 → 从对应队列获取帧 → 处理帧数据 → 合成输出
    ↓
关闭源事件 → 停止解复用线程 → 停止解码线程 → 清空队列 → 通知过滤线程
    ↓
过滤线程更新状态标志 → 停止处理对应流 → 释放相关资源
```

## 6. 关键设计特点

### 6.1 状态标志控制
- 使用 `std::atomic<bool>` 确保线程安全
- 各线程根据状态标志决定是否工作
- 支持动态开启/关闭各路流

### 6.2 队列容量控制
- 视频帧队列：最大2帧
- 音频帧队列：最大2帧
- 包队列：视频2个包，音频3个包

### 6.3 时间同步机制
- 视频流：33ms间隔同步
- 音频流：实时处理
- 支持暂停/恢复功能

### 6.4 资源管理
- 及时释放不再使用的帧
- 队列支持优雅关闭
- 线程支持优雅退出

### 6.5 错误处理
- 完善的错误检测和恢复
- 异常安全的内存管理
- 线程安全的资源清理

## 总结

FFVFilter和FFAFilter的控制机制体现了现代音视频处理软件的复杂性和精密性：

1. **双过滤器架构**: 视频和音频分别处理，职责清晰
2. **状态标志控制**: 使用原子变量确保线程安全的状态管理
3. **队列同步机制**: 支持阻塞等待，避免忙等待
4. **事件驱动控制**: 通过事件系统实现异步控制
5. **资源管理**: 完善的资源分配和释放机制
6. **时间同步**: 支持多路流的时间同步和暂停/恢复

这种设计确保了系统的高性能、高可靠性和良好的用户体验，每一路流的开启、增加、销毁都得到了精心的管理和控制。
