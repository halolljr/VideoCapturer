# 五路流数据生命周期详解

## 数据生命周期概述

每一路流的数据都经历从**产生** → **传输** → **处理** → **合成** → **输出** → **销毁**的完整生命周期。整个过程中涉及多个内存管理节点和资源控制机制。

## 1. 数据生命周期阶段

### 阶段2: 数据传输 (Data Transmission)

#### 2.1 队列缓冲机制
```cpp
// 视频包队列 - 容量限制避免延迟
class FFVPacketQueue {
private:
    std::queue<FFPacket*> pktQueue;
    size_t maxSize = 2;  // 最大容量2个包
    
public:
    void enqueue(AVPacket* pkt) {
        std::unique_lock<std::mutex> lock(mutex);
        // 等待队列有空间
        cond.wait(lock, [this]() { 
            return pktQueue.size() < MAX_PACKET_SIZE || m_stop.load(); 
        });
        
        // 创建FFPacket并加入队列
        FFPacket* ffpkt = static_cast<FFPacket*>(av_mallocz(sizeof(FFPacket)));
        av_packet_move_ref(&ffpkt->packet, pkt);
        ffpkt->serial = serial;
        ffpkt->type = NORMAL;
        
        pktQueue.push(ffpkt);
        cond.notify_one();
    }
};
```

#### 2.2 线程安全传输
- 使用 `std::mutex` 保护队列操作
- 使用 `std::condition_variable` 实现阻塞等待
- 支持优雅关闭和资源清理

### 阶段3: 数据解码 (Data Decoding)

#### 3.1 解码器处理
```cpp
void FFVDecoder::decode(AVPacket* packet) {
    // 发送数据包到解码器
    int ret = avcodec_send_packet(codecCtx, packet);
    
    AVFrame* frame = av_frame_alloc();
    while(ret >= 0) {
        // 接收解码后的帧
        ret = avcodec_receive_frame(codecCtx, frame);
        
        if(ret >= 0) {
            // 格式转换（如果需要）
            if(resampler) {
                AVFrame* swsFrame = nullptr;
                resampler->resample(frame, &swsFrame);
                av_frame_unref(frame);
                
                // 克隆帧并送入队列
                AVFrame* decoderFrame = av_frame_clone(swsFrame);
                frmQueue->enqueue(decoderFrame);
                av_frame_free(&decoderFrame);
                
                av_frame_unref(swsFrame);
                av_frame_free(&swsFrame);
            }
            else {
                // 直接送入队列
                AVFrame* decoderFrame = av_frame_clone(frame);
                frmQueue->enqueue(decoderFrame);
                av_frame_free(&decoderFrame);
            }
        }
    }
    av_frame_free(&frame);
}
```

#### 3.2 帧队列管理
```cpp
// 视频帧队列 - 容量限制
class FFVFrameQueue {
private:
    std::queue<AVFrame*> frmQueue;
    size_t maxSize = 2;  // 最大容量2帧
    
public:
    void enqueue(AVFrame* srcFrame) {
        std::unique_lock<std::mutex> lock(mutex);
        cond.wait(lock, [this]() { 
            return frmQueue.size() < MAX_FRAME_SIZE || m_stop.load(); 
        });
        
        // 移动引用，避免拷贝
        AVFrame* destFrame = av_frame_alloc();
        av_frame_move_ref(destFrame, srcFrame);
        av_frame_unref(srcFrame);
        frmQueue.push(destFrame);
        cond.notify_one();
    }
};
```

```cpp
void FFOverlayProcessor::overlayImage(cv::Mat& foreground, int x, int y, int w, int h) {

    int y2 = std::min(y + h, background.rows);

    cv::Rect roi_fg(fg_x1, fg_y1, fg_x2 - fg_x1, fg_y2 - fg_y1);
    cv::Mat foreground_roi = resized_foreground(roi_fg);
    
    cv::Rect roi_bg(x1, y1, x2 - x1, y2 - y1);
    cv::Mat background_roi = background(roi_bg);
    
    // 叠加到背景
    foreground_roi.copyTo(background_roi);
}
```

### 阶段6: 数据编码 (Data Encoding)

#### 6.1 编码器处理
```cpp
int FFVEncoder::encode(AVFrame* frame, int streamIndex, int64_t pts, AVRational timeBase) {
    // 时间戳转换
    pts = av_rescale_q(pts, timeBase, codecCtx->time_base);
    if(pts <= lastPts) {
        pts = lastPts + 1;
    }
    lastPts = pts;
    frame->pts = pts;
    
    // 发送帧到编码器
    int ret = avcodec_send_frame(codecCtx, frame);
    
    while(1) {
        AVPacket* pkt = av_packet_alloc();
        ret = avcodec_receive_packet(codecCtx, pkt);
        
        if(ret >= 0) {
            pkt->stream_index = streamIndex;
            pktQueue->enqueue(pkt);  // 送入编码包队列
            av_packet_free(&pkt);
        }
        else if(ret == AVERROR(EAGAIN)) {
            av_packet_free(&pkt);
            break;
        }
    }
    return 0;
}
```

```cpp
// 队列清理
void FFVPacketQueue::clearQueue() {
    std::lock_guard<std::mutex> lock(mutex);
    while(!pktQueue.empty()) {
        FFPacket* ffpkt = pktQueue.front();
        pktQueue.pop();
        if(ffpkt != nullptr) {
            av_packet_unref(&ffpkt->packet);
            av_freep(&ffpkt);
        }
    }
}

// 帧队列清理
void FFVFrameQueue::clearQueue() {
    std::lock_guard<std::mutex> lock(mutex);
    while(!frmQueue.empty()) {
        AVFrame* frame = frmQueue.front();
        frmQueue.pop();
        if(frame) {
            av_frame_unref(frame);
            av_frame_free(&frame);
        }
    }
}
```

## 5. 性能优化策略

### 5.1 内存池管理
```cpp
// 预分配内存池，避免频繁分配/释放
class FramePool {
private:
    std::queue<AVFrame*> availableFrames;
    std::mutex poolMutex;
    
public:
    AVFrame* acquireFrame() {
        std::lock_guard<std::mutex> lock(poolMutex);
        if(!availableFrames.empty()) {
            AVFrame* frame = availableFrames.front();
            availableFrames.pop();
            return frame;
        }
        return av_frame_alloc();
    }
    
    void releaseFrame(AVFrame* frame) {
        std::lock_guard<std::mutex> lock(poolMutex);
        av_frame_unref(frame);
        availableFrames.push(frame);
    }
};
```

## 总结

五路流数据的生命周期管理体现了现代音视频处理软件的复杂性和精密性：

1. **完整的数据流**: 从产生到销毁的完整生命周期管理
2. **高效的内存管理**: 引用计数、移动语义、内存池等优化策略
3. **线程安全**: 多线程环境下的数据同步和资源管理
4. **实时处理**: 队列容量限制、异步处理等实时性保证
5. **错误恢复**: 完善的错误检测和资源清理机制

这种设计确保了系统的高性能、高可靠性和良好的用户体验。
