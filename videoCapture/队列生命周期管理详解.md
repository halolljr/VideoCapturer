# 过滤队列和编码队列生命周期管理详解

## 队列生命周期概述

在这个五路流处理系统中，队列分为两个层次：
1. **源队列**：与具体源绑定的队列，随源的开启/关闭而管理
2. **全局队列**：过滤队列和编码队列，具有独立的生命周期

## 1. 队列分类和生命周期

### 1.1 源队列（随源生命周期管理）

### 3.2 源队列的状态控制

#### 队列阻塞等待机制
```cpp
AVFrame* FFVFrameQueue::dequeue() {
    std::unique_lock<std::mutex> lock(mutex);
    if(m_stop) {
        return nullptr;
    }
    // 等待队列有数据或停止
    cond.wait(lock, [this]() { return !frmQueue.empty() || m_stop.load(); });
    
    if(m_stop.load()) {
        return nullptr;
    }
    
    AVFrame* frame = frmQueue.front();
    frmQueue.pop();
    cond.notify_one();
    return frame;
}
```

#### 队列容量控制
```cpp
void FFVFrameQueue::enqueue(AVFrame* srcFrame) {
    std::unique_lock<std::mutex> lock(mutex);
    // 等待队列有空间或停止
    cond.wait(lock, [this]() { return frmQueue.size() < MAX_FRAME_SIZE || m_stop.load(); });
    
    if(m_stop.load()) {
        av_frame_unref(srcFrame);
        return;
    }
    
    AVFrame* destFrame = av_frame_alloc();
    av_frame_move_ref(destFrame, srcFrame);
    av_frame_unref(srcFrame);
    frmQueue.push(destFrame);
    cond.notify_one();
}
```

## 5. 队列如何管控音视频流

### 5.1 队列作为流控制中心

#### 视频流控制
```cpp
void FFVFilterThread::run() {
    while(!m_stop) {
        // 检查各流状态
        bool hasVideo = videoFlag.load();
        bool hasScreen = screenFlag.load();
        bool hasCamera = cameraFlag.load();
        
        // 根据状态从对应队列获取帧
        if(hasScreen) {
            screenFrame = frmQueue1->dequeue();  // 从屏幕队列获取
        }
        if(hasCamera) {
            cameraFrame = frmQueue2->dequeue();  // 从摄像头队列获取
        }
        if(hasVideo) {
            videoFrame = frmQueue3->dequeue();   // 从视频队列获取
        }
        
        // 处理后的帧送入编码队列
        if(hasEncoder && !hasPause) {
            filter->sendEncodeFrame(encodeFrame);
        }
    }
}
```

#### 音频流控制
```cpp
void FFAFilterThread::run() {
    while(!m_stop) {
        bool microphoneActive = microphoneFlag.load();
        bool audioActive = audioFlag.load();
        
        // 根据状态从对应队列获取帧
        if(audioActive && microphoneActive) {
            audioFrame = frmQueue1->dequeue();      // 从音频队列获取
            microphoneFrame = frmQueue2->dequeue(); // 从麦克风队列获取
        }
        else if(audioActive) {
            audioFrame = frmQueue1->dequeue();      // 从音频队列获取
        }
        else if(microphoneActive) {
            microphoneFrame = frmQueue2->dequeue(); // 从麦克风队列获取
        }
        
        // 处理后的帧送入编码队列
        if(encoderActive && !pauseActive) {
            filter->sendFilter(audioFrame, microphoneFrame, start, pauseTime);
        }
    }
}
```

## 6. 队列的持久性机制

### 6.1 全局队列的持久性

#### 过滤队列和编码队列的特点
- **生命周期**：从系统启动到系统关闭
- **状态管理**：通过start/stop控制工作状态
- **内容管理**：通过flush/clear清空内容
- **线程安全**：使用互斥锁和条件变量

#### 队列状态转换
```
创建 → 启动 → 工作 → 停止 → 清理 → 销毁
  ↓      ↓      ↓      ↓      ↓      ↓
初始化  开始   处理   暂停   清空   释放
```

### 6.2 源队列的临时性

#### 源队列的特点
- **生命周期**：随源的开启/关闭
- **状态管理**：通过start/close控制
- **内容管理**：自动清空和释放
- **线程安全**：支持多线程访问

#### 源队列状态转换
```
创建 → 启动 → 工作 → 关闭 → 清理
  ↓      ↓      ↓      ↓      ↓
初始化  开始   处理   停止   清空
```

## 8. 队列生命周期总结

### 8.1 队列分类总结

#### 源队列（临时性）
- **生命周期**：随源开启/关闭
- **管理方式**：通过事件系统控制
- **特点**：与具体源绑定，源关闭时队列停止工作

#### 全局队列（持久性）
- **生命周期**：从系统启动到关闭
- **管理方式**：通过录制开始/停止控制
- **特点**：独立于具体源，负责全局处理

### 8.2 队列管控机制总结

#### 流控制机制
1. **状态标志控制**：使用原子变量控制流状态
2. **队列容量控制**：限制队列大小避免延迟
3. **阻塞等待机制**：队列为空时阻塞等待
4. **时间同步机制**：支持多路流时间同步
5. **暂停恢复机制**：支持流的暂停和恢复

#### 资源管理机制
1. **及时释放**：不再使用的帧及时释放
2. **优雅关闭**：支持队列的优雅关闭
3. **线程安全**：使用互斥锁保护队列操作
4. **内存管理**：使用FFmpeg内存管理函数

## 总结

过滤队列和编码队列具有**独立的生命周期**，不会因为单个源的销毁而销毁：

1. **过滤队列和编码队列**：从系统启动到关闭一直存在，通过start/stop控制工作状态
2. **源队列**：随源的开启/关闭而管理，具有临时性
3. **队列管控机制**：通过状态标志、容量控制、阻塞等待等方式管控音视频流
4. **资源管理**：完善的资源分配和释放机制，确保系统稳定运行

这种设计确保了系统的高效性和可靠性，每一路流都得到了精心的管理和控制。
